Video ini membahas Windows operating system architecture yang terbagi menjadi dua komponen utama, yaitu user mode dan kernel mode. Pada user mode, aplikasi berjalan menggunakan permission yang terbatas, sedangkan kernel mode memiliki akses penuh terhadap komponen hardware melalui device drivers. Selain itu, dijelaskan fungsi system processes yang berjalan di background untuk mengelola berbagai tugas sistem, serta peran Windows Registry sebagai hierarchical database tempat menyimpan configuration settings untuk software, hardware, maupun user. Video ini juga memaparkan cara kerja background services seperti print spooler dan Windows Update yang beroperasi tanpa interaksi langsung dari user. Dalam pengelolaan data, Windows mengandalkan NTFS file system yang mendukung fitur seperti permissions, encryption melalui BitLocker, dan compression. Pada bagian kedua, disampaikan practical demonstration untuk aspiring system administrator yang mencakup pemantauan performance PC, penggunaan memori, serta startup apps melalui Task Manager. Dilanjutkan dengan pengelolaan layanan sistem secara mandiri melalui services.msc, hingga langkah troubleshooting dengan memeriksa registry editor menggunakan perintah regedit.
